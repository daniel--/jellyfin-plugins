# Jellyfin plugins

Plugin repository for my Jellyfin plugins. In Dashboard → Plugins → Repositories, add:

```
https://raw.githubusercontent.com/daniel--/jellyfin-plugins/gh-pages/manifest.json
```

| Plugin | Source |
|---|---|
| Smart Shuffle | [jellyfin-smart-shuffle](https://github.com/daniel--/jellyfin-smart-shuffle) |
| Session Persist | [jellyfin-session-persist](https://github.com/daniel--/jellyfin-session-persist) |

The manifest lives on the `gh-pages` branch. Each plugin's release workflow adds its new versions.
